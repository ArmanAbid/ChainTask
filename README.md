# ChainTask

ChainTask is a minimal on-chain job marketplace built on Cardano.

It allows clients to create jobs and lock funds in a smart contract escrow, ensuring that payment is securely held until the work is completed. Builders can apply for jobs, and once selected, they are paid directly from the escrow after approval.

The goal of this project is to demonstrate a simple and trustless way to handle freelance payments on-chain without relying on intermediaries.
